# 🚀 autoFormer

**autoFormer** is a Python automation script built using Selenium that automatically fills and submits Google Forms for testing and development purposes.

> ⚠️ This tool is intended **only for forms you own or have permission to test**. Do not use it for spam or unauthorized submissions.

---

## 📌 Features

- Automatically detects and fills Google Form questions  
- Supports text, textarea, radio buttons, and checkboxes  
- Randomized input generation for realistic responses  
- Multiple response submission support (with permission)  
- Custom delay between submissions  
- Headless mode (run without opening browser)  
- Test mode (fill without submitting)  
- Easily customizable sample data  

## 🛠️ Tech Stack

- Python  
- Selenium WebDriver  
- Google Chrome  
- ChromeDriver (via `webdriver-manager`)
